# Motion

- Duration: 150 ms (`--wl-dur-base`), ease-out.
- Dialogs and toasts rise into place (opacity and a 6 px translation). Skeletons shimmer while loading.
- **Reduced motion:** inside the Folio root, animations and transitions are removed (and durations reduced to 0.01 ms); skeleton shimmer is hidden. The host page is not affected.
